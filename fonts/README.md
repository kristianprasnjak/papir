# Font

Papir za tekst papira koristi **JetBrains Mono NL** (inačica bez ligatura, da se svaki znak vidi kakav jest, kao u Notepadu). Font je ugrađen u aplikaciju (`app/src/main/res/font/`), pa radi bez interneta.

Licenca: SIL Open Font License 1.1, vidi [JetBrainsMono-OFL.txt](JetBrainsMono-OFL.txt). Datoteke su pretvorene iz woff2 u ttf bez ikakve izmjene oblika slova.
